# Brand — RONRIKU

_Status: established_

RONRIKU feels like a compact reasoning instrument: calm, precise, mysterious, and competitive. The visual language combines a retro pixel interface, minimal low-poly 3D, and an abstract intelligence laboratory.

## Palette

| Token | Value | Use |
|---|---:|---|
| Graphite | `#28292F` | Primary surface |
| Near Black | `#17181C` | Raised dark surface |
| Black | `#090A0C` | Deep background |
| Blue Grey | `#536971` | Secondary metadata |
| Deep Blue | `#135B73` | Board shadow tiles |
| Teal | `#11C5B3` | Brand accent and primary action |
| Yellow | `#E8DA37` | Interactive cubes and focus |
| Off White | `#E7E8E5` | Primary text |

Use square corners, an 8 px layout rhythm, pixel display lettering, terse copy, and restrained 100–250 ms motion. The puzzle object is the hero. Wallet and reward language stays off the primary Daily surface.
