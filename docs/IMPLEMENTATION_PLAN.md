## Phase 0

- Inventory repository, references, Unity editor, Android modules, Java, .NET, Git, and device bridge.
- Preserve the two supplied source images and map them to the canonical reference paths.
- Establish a Unity project through the installed editor.
- Record architecture, risks, and exact commands.

## Phase 1

- Create a single boot scene through a deterministic editor build script.
- Build a portrait shell with safe-area handling and responsive scale.
- Render the profile header, DAILY title, isometric board, cubes, metadata, BEGIN action, and five-tab navigation from code-owned presentation components.
- Route BEGIN into a spatial puzzle host and Back to Home.
- Add centralized theme, reduced-motion, and haptic foundations.
- Compile, run EditMode tests, render screenshots at narrow/typical/tall portrait sizes, build Android, and install/launch when a device is available.

## Phase 1 acceptance checks

- Home hierarchy matches `home-v2`; bottom navigation follows `home-v1`.
- Touch targets are at least 48 logical pixels.
- Text and meaningful controls maintain readable contrast.
- Screen adapts at 720×1600, 1080×2400, and 1440×3200 without overlap.
- BEGIN visibly routes into the puzzle host.
- Android output is produced by Unity; install and launch status is recorded separately.
